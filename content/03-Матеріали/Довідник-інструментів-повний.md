| Інструмент | Тип | Env Variable | Безкоштовно | Сильні сторони |
|-----------|-----|-------------|------------|---------------|

| **Perplexity** | AI+пошук | `PERPLEXITY_API_KEY` | Обмежено | AI-відповіді з цитатами, Deep Research |
| **Exa AI** | Семантичний пошук | `EXA_API_KEY` | Обмежено | People/company mode, RAG-якість |
| **Tavily** | Agent-пошук | `TAVILY_API_KEY` | Обмежено | Оптимізований для AI-агентів |
| **Jina AI** | URL reader + пошук | `JINA_API_KEY` | ✓ | URL→Markdown, DeepSearch |
| **Parallel AI** | AI пошук | `PARALLEL_API_KEY` | ✓ | Search + extract |
| **Google (ручний)** | Пошук | Немає | ✓ | Найширше покриття |

## Скрейпінг соціальних мереж

### Apify (55+ акторів)
Основний змінна: `APIFY_API_TOKEN`

| Платформа | Актор | Команда |
|-----------|-------|---------|
| LinkedIn | apify/linkedin-scraper | `apify.sh linkedin <url>` |
| Instagram профіль | apify/instagram-scraper | `apify.sh instagram <handle>` |
| Instagram теги | apify/instagram-tagged-scraper | `run-actor.sh ...` |
| Instagram коменти | apify/instagram-comment-scraper | |
| Facebook сторінки | apify/facebook-pages-scraper | |
| Facebook контакти | apify/facebook-page-contact-information | |
| TikTok профіль | clockworks/tiktok-profile-scraper | |
| TikTok відео | clockworks/tiktok-scraper | |
| TikTok пошук юзерів | clockworks/tiktok-user-search-scraper | |
| YouTube канал | streamers/youtube-channel-scraper | |
| Google Maps | compass/crawler-google-places | |
| Контакти з сайту | vdrmota/contact-info-scraper | |

**Запуск:**
```bash
bash scripts/run-actor.sh "actor/id" '{"input":"json"}'
bash scripts/run-actor.sh "actor/id" '{"input":"json"}' --output /tmp/out.csv
```

### Bright Data MCP
Змінна: `BRIGHTDATA_MCP_URL`

```bash
bash scripts/brightdata.sh scrape "<url>"
bash scripts/brightdata.sh search "<query>"
bash scripts/brightdata.sh search-geo "<cc>" "<query>"
bash scripts/brightdata.sh search-yandex "<query>"
```

**Переваги:** CAPTCHA bypass, JS rendering, authwall (Facebook), Yandex
