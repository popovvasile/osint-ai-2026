## MBTI: маркери поведінки

### E (Екстраверсія) vs I (Інтроверсія)

| E-маркери | I-маркери |
|----------|----------|
| Висока частота публікацій | Рідкісні публікації |
| "ми/давайте/разом" | "я помітив/я спробував" |
| Конференції, публічні виступи | Мало публічних появ |
| Велика, різноманітна аудиторія | Мала, але залучена аудиторія |
| Відкрита мережа зв'язків | Закрита, глибока мережа |

### S (Відчуття) vs N (Інтуїція)

| S-маркери | N-маркери |
|----------|----------|
| Конкретні приклади, цифри | Зв'язки між різними сферами |
| Покрокові інструкції | Прогнози трендів |
| Лінійна кар'єра | Кар'єрні переходи між сферами |
| Фото конкретних речей | Метафори, абстрактні концепції |

### T (Мислення) vs F (Почуття)

| T-маркери | F-маркери |
|----------|----------|
| "метрики/ROI/оптимізація" | "я розумію/це важко" |
| Безособистий аналіз | Вразливість, відкритість |
| Мало або жодних емодзі | Теплі емодзі (❤️ 🤗 ✨) |
| Дебати і аргументи | Уникання конфліктів |

### J (Судження) vs P (Сприйняття)

| J-маркери | P-маркери |
|----------|----------|
| Регулярний графік публікацій | Нерегулярні публікації |
| Структурований контент | Спонтанний контент |
| Довгі терміни в компаніях | Часті зміни |
| Цілеорієнтований | Процесорієнтований |

## Big Five (OCEAN)

| Вимір | Що вимірювати |
|-------|-------------|
| **Openness** | Різноманітність кар'єри, подорожі, мистецтво, експериментальний контент |
| **Conscientiousness** | Регулярність публікацій, кар'єрна прогресія, структуроване письмо |
| **Extraversion** | Активність у соцмережах, публічні виступи, колаборації |
| **Agreeableness** | Тепло у мові, уникання конфліктів, орієнтація на спільноту |
| **Neuroticism** | Хеджування, маркери тривожності, перфекціонізм |

## Кількісна оцінка стилю

```python
# Розрахувати для зразків тексту:
text = "зразок постів або статей"

words = text.split()
sentences = text.split('.')

avg_sentence_length = len(words) / len(sentences)
emoji_density = count_emojis(text) / len(words) * 100
self_reference = text.lower().count('я') / len(words) * 100
hedge_words = sum(1 for w in words if w in ['можливо','мабуть','схоже','здається'])
```

**Норми:**
- Коротко: <10 слів/речення
- Середньо: 10-20
- Довго: 20+

## Цінності: виводимо з дій

| Що людина РОБИТЬ | Що це говорить про цінності |
|-----------------|---------------------------|
| Публікує освітній контент безкоштовно | Навчання, щедрість |
| Демонструє дорогі речі | Статус, матеріальний успіх |
| Захищає колег публічно | Лояльність, справедливість |
| Уникає соціальних мереж | Приватність, фокус |
| Часто змінює компанії | Свобода > стабільність |
| Залишається в компанії 10+ років | Стабільність, лояльність |

**Правило:** Цінності = те що роблять, коли ніхто не дивиться
