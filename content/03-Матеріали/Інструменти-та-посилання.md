## Fabric: AI-фреймворк для аналізу контенту

[danielmiessler/fabric](https://github.com/danielmiessler/fabric) — відкритий фреймворк, що застосовує структуровані «патерни» до будь-якого контенту.

**Установка:**
```bash
go install github.com/danielmiessler/fabric@latest
fabric --setup   # налаштування API-ключів
```

**Ключові OSINT-патерни:**
```bash
fabric -y 'URL відео' --stream extract_wisdom   # витяг ідей, фактів, цитат
fabric --text "текст" --stream summarize         # резюме для керівництва
fabric --text "текст" --stream analyze_claims    # перевірка тверджень на логіку
fabric --text "нотатки" --stream create_report   # форматований звіт
```
