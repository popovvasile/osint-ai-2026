Популярні платформи «AI»

Я рідко використовую популярні платформи «AI», оскільки майже всі вони або погано підходять, або є невідповідними для збору інформації. Як уже згадувалося, майже всі вони збирають ваші запити та дані під час використання, а багато з них також генерують некоректні результати. Нижче наведено кілька популярних платформ, які ви можете протестувати, але будьте обережні при використанні їх у розслідуваннях або для роботи з чутливою інформацією. Наразі існують тисячі «AI» інструментів та сайтів, тож цей список є лише невеликою частиною загальної екосистеми.

У контексті OSINT **комунікації** означають обмін інформацією перед, під час та після розслідувань або аналітичних операцій. При виборі інструментів завжди є компроміс між **конфіденційністю, безпекою, функціональністю та вартістю**.

Нижче наведено **зразки запитів** для роботи з AI в OSINT, які можна адаптувати під свої потреби.

**Структура ефективного OSINT-запиту**

📌 **Компоненти запиту:**

1. **Task (Завдання)** – Що потрібно зробити?
2. **Topic (Тема)** – Наприклад, "OSINT".
3. **Role (Роль AI)** – Відповідай як OSINT-аналітик, кіберексперт тощо.
4. **Style (Стиль)** – Діловий, науковий, формальний.
5. **Tone (Тон)** – Настрій відповіді (не обов'язково критично).
6. **Audience (Аудиторія)** – Наприклад, просте пояснення для новачка.
7. **Length (Довжина)** – Стисла відповідь або розгорнута аналітика.
8. **Format (Формат)** – HTML, Markdown, таблиця тощо.


📌 **Приклад структурованого OSINT-запиту:**
`Відповідай як аналітик розвідки. Створи список ресурсів з OSINT, опублікованих після 2023 року. Список повинен містити 20 пунктів у форматі Markdown.`

Технічна документація та методологія Web3 OSINT

1. 
Визначення цілей дослідження: ідентифікація підозрілих гаманців, транзакцій, власників активів або зв’язків між суб’єктами у Web3.
2. Збір первинних даних:

- Використання блокчейн-експлорерів:
    - [Etherscan](https://etherscan.io/)
    - [BscScan](https://bscscan.com/)
    - [Polygonscan](https://polygonscan.com/)
- Приклад використання:

```javascript
import requests
address = "0x123456789abcdef..."
url = f"https://api.etherscan.io/api?module=account&action=balance&address={address}&apikey=YOUR_API_KEY"
response = requests.get(url)
print(response.json())
```

- Аналіз смарт-контрактів:
    - [OpenZeppelin](https://openzeppelin.com/)
    - [Dune Analytics](https://dune.com/)
- Витяг адрес:
    - [ENS Domains](https://ens.domains/)
    - [Unstoppable Domains](https://unstoppabledomains.com/)
- Приклад пошуку ENS-домена:

```javascript
import requests
ens_name = "example.eth"
url = f"https://api.ens.domains/v1/names/{ens_name}"
response = requests.get(url)
print(response.json())
```

3. Аналіз ончейн-активності:

- Отримання історії транзакцій гаманця.
- Визначення токенів (ERC-20, ERC-721, ERC-1155) у володінні.
- Аналіз використання міксерів:
    - [Tornado Cash](https://tornado.cash/)
- Приклад отримання транзакцій гаманця:

```javascript
url = f"https://api.etherscan.io/api?module=account&action=txlist&address={address}&apikey=YOUR_API_KEY"
response = requests.get(url)
print(response.json())
```

4. Аналіз позачергових (off-chain) даних:

- Пошук зв’язків через соціальні мережі:
    - [Twitter](https://twitter.com/)
    - [Discord](https://discord.com/)
    - [Telegram](https://telegram.org/)
    - [Reddit](https://www.reddit.com/)
- Використання OSINT-інструментів:
    - [Sherlock](https://github.com/sherlock-project/sherlock)
- Приклад використання Sherlock для пошуку профілю користувача:

```javascript
python3 sherlock.py username
```

5. Виявлення шаблонів поведінки:

- Кореляція транзакцій за часовими мітками.
- Визначення мережевих взаємодій між гаманцями.
- Кластеризація гаманців на основі взаємодій.

6. Верифікація особистості:

- Перевірка активності на NFT-маркетплейсах:
    - [OpenSea](https://opensea.io/)
    - [Rarible](https://rarible.com/)
    - [LooksRare](https://looksrare.org/)
- Використання зворотного пошуку зображень:

8. Документування результатів:

- Створення звітів про виявлені підозрілі активності.
- Архівація та збереження доказів.

9. Забезпечення OPSEC під час досліджень:

- Використання анонімних облікових записів.
- Захист мережевого підключення через [VPN](https://protonvpn.com/) та [Tor](https://www.torproject.org/).
- Використання окремого робочого середовища.

10. Завершення розслідування:

- Оцінка рівня довіри до отриманих даних.
- Визначення подальших дій: передача правоохоронним органам, повідомлення постраждалих.
- Аналіз ефективності проведеного розслідування та покращення методів збору даних.
