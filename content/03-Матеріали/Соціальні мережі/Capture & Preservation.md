### Технічна документація: Використання інструментів для OSINT

#### Вступ

Цей документ описує використання інструментів для захоплення медіа-контенту в рамках OSINT-досліджень. Інструменти забезпечують ефективну роботу з даними, включаючи захоплення зображень, відео, тексту та автоматизацію процесів для аналізу та звітності.




### Захоплення екрана: Windows

1. **Snipping Tool (Інструмент обрізки)**:
    - Введіть у пошуку Windows "snip" для швидкого доступу.
    - Додайте інструмент до панелі завдань.
    - Використовуйте функцію затримки для захоплення прихованих елементів вікна.
2. **Інструменти для відео та зображень**:
    - **Snagit**: Підтримує редагування та запис відео. [Завантажити](https://www.techsmith.com/screen-capture.html)
    - **Camtasia**: Розширені можливості відеомонтажу (платний інструмент). [Завантажити](https://www.techsmith.com/video-editor.html)
    - **ShareX**: Відкритий інструмент із підтримкою автопрокрутки, OCR та роботи з файлами. [Завантажити](https://getsharex.com/downloads)
3. **Гарячі клавіші (ShareX)**:
    - Ctrl + PrintScreen: захоплення області.
    - PrintScreen: весь екран.
    - Alt + PrintScreen: активне вікно.
    - Ctrl + Shift + PrintScreen: запис відео.




### Захоплення екрана: Mac

1. **Комбінації клавіш для MacOS**:
    - Command + Shift + 3: знімок всього екрану.
    - Command + Shift + 4: вибір області.
    - Command + Shift + 4 + пробіл: захоплення окремого вікна.
2. **QuickTime**:
    - Для запису відео оберіть **File -> New Screen Recording**.




### Захоплення веб-контенту

1. **Firefox**:
    - Використовуйте вбудований інструмент «Take a Screenshot» для вибіркового або повного знімка сторінки.
    - **DownThemAll** для масового завантаження. [Завантажити](https://www.downthemall.org/)
2. **Інші методи**:
    - Використовуйте консоль розробника для створення повного скріншота.




### Захоплення зображень та відео

1. **YouTube**:
    - **VideoDownloadHelper**: Завантаження відео з YouTube та інших платформ. [Завантажити](https://addons.mozilla.org/en-US/firefox/addon/video-downloadhelper/)
    - **FFmpeg**: Інструмент для роботи з відео через командний рядок. [Завантажити](https://ffmpeg.org/)
2. **Соцмережі**:
    - **Instagram/TikTok**: Сторонні сервіси або розширення браузера: [Dredown для Instagram](https://www.dredown.com/instagram) | [TikTokзавантажувач](https://www.expertsphp.com/download.php).
3. **Інші інструменти**:
    - **Bulk Image Downloader**: Для автоматизації завантаження зображень. [Завантажити](https://bulkimagedownloader.com/)

### Додаткові функції ShareX

1. **OCR**: Витяг тексту зі знімків екрана або PDF.
2. **Редактор зображень**: Видалення конфіденційної інформації.
3. **Конвертер відео**: Оптимізація файлів.
4. **Індексація папок**: Створення списків цифрових доказів.

3. Перевіряйте завантажені файли хеш-валідаторами.
