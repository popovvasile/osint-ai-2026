### Вступ та випадки використання

Не всі звіти включають розділ аналізу, але в ньому можна використовувати графічні елементи для кращого розуміння текстового викладу. Це можуть бути часові шкали ключових подій або графи, які показують зв’язки між людьми, групами, місцями або вебсайтами. Не всі розслідування вимагають такого рівня деталізації, і не всі мають доступ до відповідних інструментів, але це може бути корисно для значних випадків.

Цей вступ охоплює доступні інструменти для створення графів і часових шкал. У майбутніх уроках будуть детальні демонстрації їх використання для візуалізації результатів розслідувань. Традиційно ці інструменти використовуються для аналізу мереж, організацій та зв’язків між цілями, але їх також можна застосувати для візуалізації робочих процесів.

### 1.4 Основи аналізу зв’язків

- Лінії показують зв’язок між двома об’єктами (люди, акаунти, адреси, транспортні засоби тощо).
- Лінії зі стрілками вказують напрямок зв’язку або комунікації.
- Стрілки можуть відображати підписки (взаємна підписка позначається стрілками на обох кінцях).
- Товщина ліній відповідає рівню впевненості в існуванні зв’язку.
- Рекомендується використовувати легенду для пояснення.
- **Матриця асоціацій** демонструє ступінь зв’язку:
    - Суцільні точки — підтверджені зв’язки.
    - Порожні або пунктирні — непідтверджені зв’язки.

Корисні ресурси:

- [Керівництво для аналітиків](https://www.unodc.org/documents/organized-crime/Law-Enforcement/Criminal_Intelligence_for_Analysts.pdf)

### Гайд: Використання графів зв'язків та часових шкал у розслідуваннях




### Вступ

Графи зв'язків і часові шкали — це незамінні інструменти для аналізу складних взаємозв'язків між об'єктами, подіями та процесами. Вони дозволяють:

- Візуалізувати структуру системи.
- Виявляти ключові об'єкти та їхні взаємодії.
- Покращувати інтерпретацію даних для звітів і презентацій.

Цей гайд детально розкриває методи створення графів і часових шкал, приклади їх використання та ресурси для освоєння цих інструментів.




### 1. Інструменти для побудови графів та часових шкал

#### **1.1 Базові інструменти**

Ці інструменти ідеально підходять для невеликих мереж і простих візуалізацій.

- **[VIS: Visual Investigative Scenarios Platform](https://vis.occrp.org/):** Платформа для створення сценаріїв розслідувань. Зручно використовувати для журналістських досліджень.
- **[Gephi](https://gephi.org/):** Відкрита платформа для створення графів і аналізу даних. Добре підходить для початківців.
- **[Draw.io](https://draw.io/):** Інструмент для створення діаграм і графів. Працює як онлайн, так і офлайн.
- **[Mindmup](https://www.mindmup.com/):** Простий інструмент для побудови ментальних карт.

#### **1.2 Потужні інструменти**

Ці інструменти використовуються для аналізу великих мереж і складних систем.

- **[Maltego](https://www.maltego.com/):** Професійний інструмент для OSINT. Підтримує автоматичне збирання даних із соцмереж, доменів, IP тощо.
- **[NodeXL](https://www.nodexlgraphgallery.org/):** Інструмент для аналізу мереж у середовищі Excel. Добре підходить для соціального аналізу.
- **i2 Analyst’s Notebook:** Один із найпотужніших інструментів для аналізу складних мереж і злочинних схем.

#### **1.3 Інструменти для створення часових шкал**

- **[Time Graphics](https://time.graphics/):** Онлайн-платформа для інтерактивних часових ліній.
- **[Preceden](https://www.preceden.com/):** Інструмент із підтримкою багатошарових часових ліній.
- **[VisJS Timeline](https://visjs.github.io/vis-timeline/docs/timeline/):** Бібліотека JavaScript для інтеграції часових ліній у веб-проекти.
- **TimelineJS:** Інструмент для створення інтерактивних часових шкал із використанням Google Sheets.




### 2. Основи побудови графів та часових шкал

#### **2.1 Елементи графа**

1. **Вузли (Nodes):** Об'єкти (люди, місця, акаунти, події).
2. **Зв'язки (Edges):** Відносини між об'єктами (наприклад, комунікація, фінансові транзакції).
3. **Атрибути вузлів і зв'язків:** Можуть включати вагу (частота зв'язку), напрямок (стрілки для комунікацій), або тип (наприклад, підтверджений чи потенційний).

#### **2.2 Використання графів**

- **Аналіз соціальних мереж:** Виявлення ключових осіб і їхніх зв'язків.
- **Розслідування фінансових злочинів:** Візуалізація транзакцій і виявлення відмивання грошей.
- **Виявлення кіберзлочинних угруповань:** Побудова зв'язків між IP-адресами, доменами та акаунтами.

#### **2.3 Побудова часових шкал**

Часові шкали дозволяють візуально відображати:

- Хронологію подій у розслідуванні.
- Зміни в активності об'єктів у часі.
- Тенденції й аномалії.

**Приклад:** Хронологія шахрайської кампанії в соціальних мережах із зазначенням ключових подій, таких як створення акаунтів, публікація реклами, запуск ботів тощо.




### 3. Приклади використання

#### **3.1 Розслідування кіберзлочинів**

- **Сценарій:** Аналіз мережі ботів, що здійснює DDoS-атаки.
- **Граф:**
    - Вузли: IP-адреси, сервери управління, атаковані сайти.
    - Зв'язки: Потоки трафіку між об'єктами.

#### **3.2 Фінансове шахрайство**

- **Сценарій:** Виявлення схеми відмивання грошей.
- **Граф:**
    - Вузли: Банківські рахунки, компанії, транзакції.
    - Зв'язки: Потоки коштів між рахунками.
    - Атрибути: Суми транзакцій, дати, типи операцій.

#### **3.3 Аналіз соцмереж**

- **Сценарій:** Виявлення осередків дезінформації.
- **Часова шкала:**
    - Події: Публікація фейкових новин, поширення в групах.
    - Динаміка: Кількість поширень у часі.




### 4. Додаткові ресурси

- **[Посібник із аналізу зв'язків](https://www.rff.com/link_analysis.php):** Як будувати графи зв'язків і використовувати їх у розслідуваннях.
- **[MCTFT Training](https://mctft.org/training/analytical-investigative-tools/):** Аналітичні інструменти для слідчих.
- **[UNODC Manual](https://www.unodc.org/documents/organized-crime/Law-Enforcement/Criminal_Intelligence_for_Analysts.pdf):** Керівництво з кримінальної аналітики.
- **Maltego Tutorials:** Офіційний навчальний курс.




### Висновок

Використання графів зв'язків і часових шкал — це ключ до глибшого розуміння складних систем і взаємозв'язків. Інструменти, описані в цьому гайді, допоможуть візуалізувати дані, виявляти ключові елементи та ефективно представляти результати розслідувань.
