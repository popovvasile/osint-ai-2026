# **Методологія OSINT для пошуку за реальними іменами**




## **1. Основні типи баз даних для пошуку за іменем**

Для пошуку людей за іменами, використовуйте спеціалізовані ресурси, які залежать від країни або міста:

- **Цивільні реєстри (Civil Records):** інформація про народження, шлюб, смерть.
- **Судові реєстри (Court Records):** дані про судові справи.
- **Реєстри виборців (Voter Records):** списки зареєстрованих виборців.
- **Бази предків (Ancestor Databases):** генеалогічні дослідження.
- **Бізнес-реєстри (Business Registries):** реєстрація підприємств та бізнесменів.
- **Ліцензійні реєстри (License Registries):** інформація про професійні ліцензії.
- **Реєстри боржників (Debtors Registries):** списки фінансових боргів.
- **Реєстри власників нерухомості (Real Estate Owners Registries):** інформація про власників нерухомості.

### **Загальне правило:**

- Національні реєстри краще за міжнародні.
- Міські реєстри краще за національні.
- Локальні (районні) реєстри краще за міські.




## **2. Пошук згадок у соціальних мережах**

### **Інструменти:**

1. **[Social-Searcher](https://social-searcher.com/):** універсальний пошук згадок у соціальних мережах.




## **3. Генерація імен користувачів за реальними іменами**

### **Інструменти:**

1. **[NAMINT](https://seintpl.github.io/NAMINT/):** генерація варіантів імен користувачів на основі імені та прізвища.
2. **[Username Generation Guide](https://github.com/soxoj/username-generation-guide):** покрокове керівництво зі створення username.
3. **Для пошуку username:** Використовуйте "[USERNAME OSINT Cheat Sheet](https://github.com/sherlock-project/sherlock)".




## **4. Варіації імен**

### **Інструменти:**

1. **[Nameberry](https://nameberry.com/search?q=john):** пошук можливих варіацій імені.




## **5. Генерація можливих email за іменем**

### **Інструменти:**

1. **[Google Sheets Email Generator](https://docs.google.com/spreadsheets/d/17URMtNmXfEZEW9oUL_taLpGaqTDcMkA79J8TRw4xnz8):** автоматична генерація варіантів email на основі імені.




## **6. Пошук у пошукових системах**

### **Рекомендації:**

- Вводьте імена латиницею.
- Використовуйте різні варіації імені.

### **Google Dorks:**

- `intitle:first name intitle:last name`
- `inurl:first name inurl:last name`
- `first name last name filetype:xls`
- `first name last name filetype:xlsx`
- `first name last name filetype:sql`

### **Автоматизація:**

- **[Marple](https://github.com/soxoj/marple):** інструмент для автоматизації пошуку в Google за іменем/прізвищем.




## **7. Пошук у IP-пошукових системах**

### **Netlas:**

- `http.title:*first name*`
- `http.title:*last name*`
- `http.meta:*first name*`
- `http.meta:*last name*`
- `ftp.banner:*first name*`
- `ftp.banner:*last name*`
- `domain:*first name*`
- `domain:*last name*`

### **Інші платформи:**

- **Censys**
- **ZoomEye**
- **Onyphe**
- **Fofa**




## **8. Додаткові екзотичні методи пошуку**

### **Пошук у неочевидних джерелах:**

1. **Краудфандингові платформи (Kickstarter, GoFundMe):** Перевіряйте кампанії, створені людиною за іменем або email.
2. **Форуми та чати:** Використовуйте пошук у архівах форумів (наприклад, через `site:forum.example.com`).
3. **Академічні бази даних:** Перевіряйте згадки імені у наукових публікаціях (Google Scholar, ResearchGate).
4. **Додатки для знайомств:** Якщо є підозра, що людина використовує додатки на кшталт Tinder чи Bumble, шукайте за варіантами імені.

### **Використання відкритих API:**

1. **LinkedIn API:** Перевіряйте інформацію про кар’єру та контакти.
2. **Twitter API:** Шукайте згадки, твіти чи профілі за іменем.

### **Аналіз зображень:**

1. Якщо доступне фото людини, виконайте зворотний пошук зображень у Google Images або TinEye.
2. Використовуйте інструменти розпізнавання облич (наприклад, PimEyes).




## **9. Приклад сценарію**

**Ім’я:** John Doe

1. **Генерація username:**
    - Використовуйте NAMINT для створення варіантів, наприклад, `johnd`, `john.doe`, `jdoe`.
2. **Пошук email:**
    - Згенеруйте email: `john.doe@gmail.com`, `j.doe@company.com`.
3. **Google Dorks:**
    - `intitle:John intitle:Doe` — пошук згадок у назвах сторінок.
4. **Соціальні мережі:**
    - Використовуйте Social-Searcher для пошуку згадок у Facebook, Twitter.
5. **IP-пошукові системи:**
    - Netlas: `http.title:*John*` — пошук у заголовках сторінок.
6. **Бази даних:**
    - Перевірте цивільні та бізнес-реєстри для підтвердження інформації.
7. **Екзотичні методи:**
    - Перевірте GoFundMe для кампаній, пов’язаних із John Doe.
    - Виконайте зворотний пошук зображень для будь-якого доступного фото.




Ця інструкція допоможе ефективно використовувати реальні імена для OSINT-аналізу. Використовуйте всі доступні інструменти та методи для отримання детальної інформації!
