## Завдання 1. Тренд · 10 хв

Покажіть, як змінюється частка illicit серед розмічених транзакцій за 49 кроками, і поясніть, що відбувається після кроку 43.

```cypher
MATCH (t:Transaction) WHERE t.class IN [1, 2]
WITH t.timeStep AS step,
     count(CASE WHEN t.class = 1 THEN 1 END) AS illicit,
     count(*) AS labelled
RETURN step, illicit, labelled,
       round(100.0 * illicit / labelled, 1) AS illicitPct
ORDER BY step;
```

1. Завантажте результат як CSV і побудуйте лінійний графік `illicitPct` за кроками (Excel, Google Sheets або Python). Позначте на ньому крок 43.
2. Порахуйте частку illicit для кроків 1–42 і 43–49 через суми `illicit` і `labelled`, а не як середнє відсотків.
3. Напишіть 2–3 речення: що змінилося і яке є альтернативне пояснення, крім «злочинців стало менше».

## Завдання 2. Патерни · 20 хв

Перевірте три патерни з заняття. До кожного дайте одне число й одне речення висновку.

**2.1. Fan-in.** Поріг визначте через перцентиль, а не «на око»:

```cypher
MATCH (w:Wallet)
WITH COUNT { (w)<-[:SENT_TO]-() } AS senders
RETURN percentileDisc(senders, 0.99) AS p99,
       percentileDisc(senders, 0.999) AS p999,
       max(senders) AS max;
```

Підставте p99.9 як поріг і порахуйте класи гаманців, які його перевищують:

```cypher
MATCH (w:Wallet)
WITH w, COUNT { (w)<-[:SENT_TO]-() } AS senders
WHERE senders >= 100   // ваш поріг
RETURN w.class AS class, count(*) AS wallets
ORDER BY class;
```

Порівняйте частку illicit серед цих гаманців із базовою (1,7 %). Чи є fan-in сам по собі ознакою злочинної активності?

**2.2. Peel chain.** Порахуйте illicit-транзакції, з яких починається ланцюжок із 5 переходів:

```cypher
MATCH p = (s:Transaction {class: 1})-[:FLOWS_TO*5]->(:Transaction)
WHERE all(t IN nodes(p) WHERE t.nOut = 2 AND t.outMin < 0.1 * t.outMax)
RETURN count(DISTINCT s) AS starts;
```

Замініть `0.1` на `0.05`. Наскільки зменшилася кількість і що це каже про форму ланцюжків?

**2.3. Експозиція.** Знайдіть три unknown-гаманці, до яких за 1–2 кроки надходили кошти від найбільшої кількості illicit-гаманців (запит може виконуватися до хвилини):

```cypher
MATCH (i:Wallet {class: 1})-[:SENT_TO*1..2]->(u:Wallet {class: 3})
WITH u, count(DISTINCT i) AS exposure
RETURN u.address AS address, exposure
ORDER BY exposure DESC LIMIT 3;
```

Для першої адреси подивіться прямих відправників: `MATCH (x:Wallet)-[:SENT_TO]->(:Wallet {address: '…'}) RETURN x.address, x.class;`. Висока експозиція, що йде через одного відправника, — сильний чи слабкий сигнал?

## Завдання 3. Спільноти · 15 хв

Знайдіть спільноти Louvain, де illicit-гаманців непропорційно багато, і виберіть у першій із них кандидата в ліди.

1. Виконайте весь `03_gds.cypher` (≈ 3–4 хв). Він запише гаманцям властивості `louvain`, `leiden`, `pagerank` і `inDeg`.
2. Складіть таблицю топ-5 спільнот за часткою illicit. Lift показує, у скільки разів ця частка вища за базову (1,7 %):

```cypher
MATCH (w:Wallet)
WITH count(*) AS total, count(CASE WHEN w.class = 1 THEN 1 END) AS totalIllicit
MATCH (w:Wallet)
WITH 1.0 * totalIllicit / total AS base, w.louvain AS community, count(*) AS size,
     count(CASE WHEN w.class = 1 THEN 1 END) AS illicit
WHERE size >= 20
RETURN community, size, illicit,
       round(100.0 * illicit / size, 1) AS illicitPct,
       round(illicit / (size * base), 1) AS lift
ORDER BY illicitPct DESC LIMIT 5;
```

3. Для спільноти з першого рядка знайдіть unknown-гаманці з найвищим PageRank — це кандидати в ліди:

```cypher
MATCH (u:Wallet {louvain: 123, class: 3})   // 123 → номер вашої спільноти
RETURN u.address AS lead, round(u.pagerank, 2) AS pagerank, u.inDeg AS senders
ORDER BY pagerank DESC LIMIT 3;
```

У кожному запуску Louvain номери спільнот різні, тому беріть номер зі своєї таблиці.

## Завдання 5. Висновок · 10 хв

Напишіть до 300 слів про один лід — адресу із завдання 2.3 або 3. Висновок має закрити п'ять пунктів:

- **Лід:** адреса і чому обрано саме її.
- **Два незалежні сигнали:** наприклад, експозиція і спільнота. Сигнали незалежні, якщо один не випливає з іншого.
- **Альтернативне пояснення:** біржа, платіжний сервіс, міксер, помилка розмітки.
- **Рівень упевненості:** низький, помірний чи високий — і чому.
- **Наступний крок:** що перевірити поза датасетом (block explorer, відкриті атрибуції адрес).
