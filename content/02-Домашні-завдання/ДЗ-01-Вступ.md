# Домашнє завдання 1: Вступ — AI в OSINT-дослідженнях

> Домашнє завдання до [[../01-Уроки/Урок-01-Вступ]]

---

## Мета

Це завдання продовжує логіку першої лекції: ми говорили про роль AI в OSINT, про важливість локальних рішень для контролю даних, а також про те, що промпт, структура інструкцій і правильна організація роботи агента є базовими практичними навичками сучасного аналітика.

**Мета:** самостійно розгорнути свого першого локального AI-агента, підключити до нього готовий skill-репозиторій, розібратися, як цей механізм працює, і підготувати власний кастомний SKILL для практичного застосування.

Після виконання цього домашнього завдання ви маєте:

- розгорнути та запустити локального AI-агента;
- зрозуміти базову логіку skill-based підходу;
- вміти аналізувати готовий skill-репозиторій (що він робить і як);
- створити власний структурований SKILL-файл.

## Завдання

---

### Завдання 1 — Встановити локального AI-агента

Оберіть і встановіть **один** із варіантів локального або локально керованого агента:

| Варіант | Опис | Складність |
|---------|------|-----------|
| **Claude Code** | CLI-агент від Anthropic — підтримує SKILL.md нативно | Середня |
| **OpenClaw** | Відкритий агентний фреймворк сумісний з SKILL.md | Середня |
| **Agent Zero** | Автономний агент з файловою системою | Середня |
| **Pi (Inflection AI)** | Conversational AI з можливостями агента | Низька |

Також підходять інші агентні фреймворки / середовища, які підтримують подібну логіку навичок, інструкцій або skills-модулів.

**Мінімальні вимоги:**
- Агент встановлено і запущено
- Є можливість надати йому інструкцій через файл або системний промпт

---

### Завдання 2 — Підключити готовий skill-репозиторій

Встановіть репозиторій [smixs/osint-skill](https://github.com/smixs/osint-skill) або інший близький за логікою skills-репозиторій.

**Що таке smixs/osint-skill:**
- Репозиторій призначений для агентів, які підтримують формат SKILL.md
- Підключається до Claude Code, OpenClaw, Codex, OpenCode та інших сумісних агентів
- Головний файл `osint/SKILL.md` — 8-фазний OSINT-пайплайн (452 рядки)
- Довідкові матеріали, шаблон досьє та набір скриптів, включно з `diagnose.sh` для самоперевірки

**Основні кроки встановлення:**
```bash
git clone https://github.com/smixs/osint-skill.git
cd osint-skill/osint/scripts && npm install && cd ../..
cp -r osint/ ~/.claude/skills/osint/   # для Claude Code
export JINA_API_KEY="jina_..."         # мінімальний безкоштовний ключ
bash osint/scripts/diagnose.sh         # перевірка середовища
```

> **Важлива примітка:** репозиторій позначений автором як **Early Beta**. Працюйте лише в контрольованому локальному середовищі. Не подавайте неперевірені дані напряму в тестові скрипти — у README окремо вказані відомі обмеження, зокрема застереження щодо shell injection для недовіреного вводу.

---

### Завдання 3 — Дослідити, як працює skill

Після встановлення коротко дослідіть та задокументуйте:

| Питання | Ваша відповідь |
|---------|----------------|
| Як агент «бачить» skill? (де файл, як передається) | |
| Яку роль відіграє файл SKILL.md? | |
| Які додаткові файли, скрипти або reference-матеріали використовуються? | |
| Як організована логіка роботи skill'а (фази, кроки)? | |
| Які залежності, API або інструменти потрібні для повноцінної роботи? | |

**На що звернути увагу в SKILL.md:**
- Кількість фаз і їхня послідовність
- Як агент приймає рішення про вартість операції
- Яку роль відіграє `diagnose.sh` на початку роботи

---

### Завдання 4 — Підготувати власний кастомний SKILL

На основі вивченого прикладу створіть власний невеликий SKILL-файл для агента. Це має бути окремий текстовий файл у подібному стилі, який описує, як агент має виконувати конкретне практичне завдання.

**Ваш кастомний SKILL може бути присвячений, наприклад:**
- Базовому OSINT-профілюванню особи
- Перевірці домену / компанії
- Збору відкритих згадок про організацію
- Первинній структуризації фактів
- Верифікації джерел
- Побудові короткого due diligence memo
- Витягу сутностей із тексту або списку джерел

**Мінімальна структура SKILL-файлу:**
```markdown
# SKILL: [Назва]
## Мета
[Що агент робить з цим skill'ом]

## Фази виконання
### Фаза 1: [Назва]
[Кроки]
### Фаза 2: [Назва]
[Кроки]

## Вивід
[Формат результату]
```

---

## Формат здачі

Надішліть одним пакетом:

- [ ] Назва агента, який ви встановили
- [ ] Короткий опис вашого середовища (ОС, версія агента)
- [ ] 5–10 речень про те, як працює підключений skill-репозиторій
- [ ] Заповнена таблиця з Завдання 3
- [ ] Ваш власний файл SKILL (`.md` або `.txt`)
- [ ] За можливості — 1–2 скріншоти або короткий лог запуску `diagnose.sh`

**Формат файлів:** Markdown (.md), Google Doc, або PDF.

## Критерії оцінювання

| Критерій | Що перевіряється |
|----------|-----------------|
| **Технічний** | Агент дійсно встановлений і запущений |
| **Розуміння** | Ваш опис репозиторію показує, що ви розібралися не лише «що це», а й «як це працює» |
| **Аналіз** | Відповіді в таблиці Завдання 3 конкретні, а не загальні |
| **Якість SKILL** | Власний SKILL структурований, логічний і придатний до реального використання |
| **Цінність** | Завдання, яке ви описали для агента, має практичну цінність для OSINT / research / due diligence |
