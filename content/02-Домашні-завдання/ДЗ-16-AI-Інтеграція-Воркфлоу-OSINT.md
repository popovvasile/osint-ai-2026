# ДЗ-16: AI-асистований аналітичний продукт
> [[02-Домашні-завдання/index|Усі завдання]] · [[01-Уроки/Урок-16-AI-Інтеграція-Воркфлоу-OSINT|Урок]]

> **Опційне завдання.** Це ДЗ не є обов'язковим для зарахування курсу. Можна виконати будь-який рівень або пропустити повністю.

**Урок:** Урок-16-AI-Інтеграція-Воркфлоу-OSINT

### Назва: «AI-асистований аналітичний продукт»

### Рівень 1 — Базовий

**Частина А — Структурований звіт:**

На основі будь-якого публічного OSINT-кейсу (новини, твіти, Telegram-канали) напишіть **Spot Report** українською мовою:
1. BLUF (1–2 речення, ключовий висновок, рівень впевненості)
2. Key Judgements (3–5 пунктів із явними рівнями впевненості)
3. Коротке тіло аналізу (факти + зв'язки)
4. Прогалини (що невідомо і що потрібно перевірити)
5. Оцінка джерел (яке джерело, наскільки надійне)

Мінімум: 400 слів. Один AI-інструмент (Claude/GPT) — задокументуйте, як саме ви його використали (який промпт, що редагували).

**Частина Б — Obsidian шаблон:**

1. Встановіть Obsidian + плагіни Dataview та Templater
2. Створіть 3 нотатки у форматі з YAML frontmatter: 2 суб'єкти + 1 подія
3. Напишіть Dataview-запит, що виводить усі суб'єкти зі статусом «ймовірно» у вигляді таблиці
4. Скріншот результату

### Рівень 2 — Розширений

**Python автоматизація:**
1. Напишіть (або згенеруйте через AI) Python-скрипт, що:
   - Читає CSV файл із подіями або повідомленнями
   - Рахує мінімум 2 агрегати (наприклад: повідомлень на день, унікальних акторів на тиждень)
   - Генерує мінімум 2 графіки (Plotly або matplotlib)
   - Зберігає результат у Markdown-файл через Jinja2-шаблон
2. У звіті задокументуйте: які промпти ви використали для генерації коду і скільки ітерацій знадобилось

**ACH матриця:**
1. Для свого кейсу побудуйте ACH матрицю з мінімум 3 гіпотезами і 5 доказами
2. Використайте промпт для Claude з розділу «Analysis of Competing Hypotheses»
3. Відредагуйте результат — що AI пропустив або неправильно оцінив?

**Геопросторова візуалізація:**
1. Виберіть мінімум 5 подій із вашого кейсу, що мають прив'язку до локації
2. Підготуйте CSV із полями `lat`, `lon`, `event_type`, `date`, `source`
3. Завантажте у QGIS (або Kepler.gl) — додайте супутникову підложку, стилізуйте точки
4. Створіть публікаційну карту: масштабна лінійка, Північ, легенда, джерело
5. Вставте карту у ваш spot report як окремий розділ «Геопросторовий аналіз»
6. Напишіть 2–3 речення, що описують просторовий патерн

### Рівень 3 — Дослідницький

**Агентний воркфлоу:**
1. Сформулюйте OSINT-задачу (аналіз домену, акаунту або мережі каналів)
2. Запустіть Claude Code як агента: напишіть один вхідний промпт і дозвольте агенту самостійно виконати кілька кроків із реальними інструментами (bash, web search, файли)
3. Збережіть трейс — лог усіх кроків агента
4. Оцініть: де агент діяв правильно, де помилився, що потребувало ручного втручання?
5. Напишіть фінальний spot report на основі результатів агента (з вашою редакцією)
