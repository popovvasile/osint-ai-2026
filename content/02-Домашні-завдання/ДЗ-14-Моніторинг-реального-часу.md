# ДЗ-14: Моніторинг у реальному часі та алерти

> **Опційне завдання.** Це ДЗ не є обов'язковим для зарахування курсу. Можна виконати будь-який піднабір завдань або пропустити повністю.

**Урок:** Урок-14-Моніторинг-реального-часу

### Завдання 1 — Базова система моніторингу
Налаштуйте систему моніторингу для 1 суб'єкта або теми:
1. Google Alert для імені суб'єкта → отримайте RSS-фід
2. Додайте 3 новинних RSS-фіди у Inoreader
3. Підпишіться на 2 Telegram-канали через RSS (RSS.app)
4. Налаштуйте keyword filter у Inoreader

Здайте: скріншот налаштованого Inoreader + 3 перших алерти

### Завдання 2 — HaveIBeenPwned
Перевірте (з дозволу власника або власний email):
1. Через сайт hibp.com: скільки витоків?
2. Через API (безкоштовний для 1 запиту/хвилину)
3. Оцініть: яка інформація скомпрометована?
4. Які OSINT-можливості відкриває ця інформація?

### Завдання 3 — Побудова алерт-системи
Побудуйте Python-скрипт що:
1. Читає Google News RSS для заданого ключового слова
2. Фільтрує результати за ключовими словами
3. Надсилає сповіщення у Telegram-бот (Telegram Bot API, безкоштовний)
