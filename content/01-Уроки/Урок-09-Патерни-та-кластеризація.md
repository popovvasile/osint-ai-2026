### Слайд 2 — Навіщо аналіз патернів?

**Один факт = одна точка.**
**Патерн = смисл.**

OSINT-аналітик не тільки збирає — він виявляє структуру:
- Чи є цикл у поведінці суб'єкта?
- Які теми домінують у спільноті?
- Куди рухається тренд?
- Хто схожий на кого?

**AI-підхід 2025-2026:** ML-алгоритми знаходять патерни у даних де людина бачить хаос

### Слайд 3 — Типи патернів у OSINT

| Тип патерну | Приклад | Інструменти |
|------------|---------|------------|
| **Часовий** | Публікації щовівторка о 9:00 → часовий пояс | Pandas, матриці активності |
| **Мовний** | Перехід з UK на RU у пості → аудиторія змінилась | NLP, topic modeling |
| **Мережевий** | Той самий набір акаунтів репостить завжди разом → ботоферма | Gephi, Betweenness |
| **Контентний** | Тематичні кластери публікацій | TF-IDF, BERTopic |
| **Поведінковий** | Різка зміна частоти публікацій → щось сталось | Anomaly detection |

### Слайд 4 — Аналіз тимчасових патернів

**Матриця активності (теплова карта):**

```python
import pandas as pd
import matplotlib.pyplot as plt

# posts_df має колонки: timestamp, platform
posts_df['hour'] = posts_df['timestamp'].dt.hour
posts_df['weekday'] = posts_df['timestamp'].dt.day_name()

# Матриця: день тижня × година дня
pivot = posts_df.pivot_table(
    index='weekday', columns='hour',
    values='id', aggfunc='count'
)

plt.figure(figsize=(14, 5))
plt.imshow(pivot, aspect='auto', cmap='YlOrRd')
plt.colorbar(label='Кількість постів')
plt.title('Матриця активності')
```

**Що виявляємо:**
- Часовий пояс (пік активності)
- Робочий vs особистий час
- Аномальна активність (ніч, вихідні)

### Слайд 5 — Кластеризація тексту

**Мета:** знайти тематичні групи без попередніх міток

**Алгоритми:**
- **K-Means** — потрібно вказати кількість кластерів
- **DBSCAN** — сам знаходить кількість, виявляє шум
- **BERTopic** — сучасний підхід на трансформерах, 2025-2026 стандарт

```python
from bertopic import BERTopic

model = BERTopic(language="multilingual")
topics, probs = model.fit_transform(documents)

# Переглянути топ-теми
print(model.get_topic_info())
```

### Слайд 6 — BERTopic для OSINT (2025-2026)

**BERTopic** — виявлення тем у корпусі документів:

1. Векторизація документів (BERT ембедінги)
2. Зменшення розмірності (UMAP)
3. Кластеризація (HDBSCAN)
4. Видалення стоп-слів (c-TF-IDF)

**Практика OSINT:**
- Аналіз 1000+ Telegram-постів → виявлення тематичних кластерів
- Аналіз новинного потоку → визначення домінантних наративів
- Аналіз коментарів → розуміння настроїв спільноти

### Слайд 8 — Виявлення аномалій

**Anomaly Detection для моніторингу:**

```python
from sklearn.ensemble import IsolationForest

# Ознаки: кількість постів на день, uniq авторів, engagement
X = df[['daily_posts', 'unique_authors', 'avg_engagement']].values

model = IsolationForest(contamination=0.05)
df['anomaly'] = model.fit_predict(X)

# anomaly = -1 → аномальний день (атака, кампанія, подія)
anomalies = df[df['anomaly'] == -1]
```

**Застосування:** виявлення координованих інформаційних кампаній, раптового зростання уваги до суб'єкта

### Слайд 12 — Обмеження алгоритмів

- **K-Means:** погано на нерівних кластерах, потребує k
- **BERTopic:** повільний на дуже великих даних (>1M документів)
- **Isolation Forest:** чутливий до параметра contamination
- **Все алгоритмічне:** виявляє кореляції, не причинно-наслідкові зв'язки

**Правило:** алгоритм вказує де дивитись, людина вирішує що це означає

### Стартовий код: матриця активності

```python
"""
Аналіз матриці активності Telegram-каналу
Для курсу AI for OSINT 2026
"""
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from datetime import datetime

# Припускаємо що у вас є CSV з колонкою 'timestamp'
# (зібраний через Telegram API або ручно)

def build_activity_matrix(csv_path, tz_offset=0):
    df = pd.read_csv(csv_path)
    df['timestamp'] = pd.to_datetime(df['timestamp'], utc=True)
    
    # Корекція часового поясу
    df['local_time'] = df['timestamp'] + pd.Timedelta(hours=tz_offset)
    df['hour'] = df['local_time'].dt.hour
    df['weekday'] = df['local_time'].dt.day_name()
    
    # Порядок днів тижня
    day_order = ['Monday', 'Tuesday', 'Wednesday',
                 'Thursday', 'Friday', 'Saturday', 'Sunday']
    
    # Побудова pivot-таблиці
    pivot = df.pivot_table(
        index='weekday', columns='hour',
        values='message_id' if 'message_id' in df.columns else df.columns[0],
        aggfunc='count',
        fill_value=0
    ).reindex(day_order)
    
    # Теплова карта
    plt.figure(figsize=(16, 6))
    sns.heatmap(pivot, cmap='YlOrRd', linewidths=0.5,
                annot=True, fmt='d', cbar_kws={'label': 'Кількість постів'})
    plt.title('Матриця активності')
    plt.xlabel('Година дня (UTC+{})'.format(tz_offset))
    plt.ylabel('День тижня')
    plt.tight_layout()
    plt.savefig('activity_matrix.png', dpi=150)
    plt.show()
    
    # Висновки
    peak_hour = pivot.values.sum(axis=0).argmax()
    peak_day = pivot.sum(axis=1).idxmax()
    print(f"Пік активності: {peak_day}, {peak_hour}:00")
    print(f"Орієнтовний часовий пояс: UTC+{tz_offset}")
    
    return pivot

# Використання:

```
