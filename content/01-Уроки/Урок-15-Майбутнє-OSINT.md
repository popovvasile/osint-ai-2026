### Слайд 2 — Де ми зараз (2026)

### Слайд 3 — Три хвилі AI в OSINT

```
Хвиля 1 (2022-2023): Текстовий AI
→ LLM для аналізу і синтезу документів
→ ChatGPT, Claude, Gemini

```

### Слайд 5 — Мультимодальний OSINT

**2026: AI бачить, чує і читає одночасно**

| Модальність | AI-можливість | OSINT-застосування |
|------------|--------------|-------------------|
| **Текст** | Читання, синтез | Вже розглянули |
| **Зображення** | Розпізнавання облич, геолокація, deepfake | Верифікація фото |
| **Відео** | Аналіз кадрів, subtitles | Транскрипція, геолокація |
| **Аудіо** | Транскрипція, ідентифікація голосу | Подкасти, дзвінки |
| **Документи** | PDF, таблиці, презентації | Фінансова звітність |
| **Геопросторові** | Супутникові знімки | Переміщення, об'єкти |

### Слайд 6 — Geospatial Intelligence: демократизація

**Революція супутникових знімків 2024-2026:**
- Planet Labs: щоденне покриття всієї Землі у 3m resolution
- Maxar: 30cm resolution комерційно доступно
- Sentinel-2 (EU): безкоштовно, 10m resolution, кожні 5 днів
- AI автоматично виявляє зміни між знімками

**Для OSINT:** відстеження будівництва, переміщень транспорту, руйнувань — без виїзду на місце

### Слайд 7 — Автоматизований аналіз змін

**Temporal Difference Analysis (AI-підхід):**

```python
# AI порівнює два супутникові знімки
from sentinel import SentinelAnalyzer

analyzer = SentinelAnalyzer()
changes = analyzer.detect_changes(
    before="2026-01-01",
    after="2026-04-14",
    location=(50.4501, 30.5234),  # Київ
    radius_km=10
)
# Повертає: зони змін, тип (будівництво/руйнування/рух)
```

### Слайд 8 — Graph Neural Networks: прогнозування зв'язків

**Link Prediction (прогнозування прихованих зв'язків):**

```
Відомо:
A → B (ділові партнери)
B → C (ділові партнери)
A → D (ділові партнери)

GNN передбачає:
C → D: 78% ймовірність зв'язку
→ Перевірити: чи дійсно пов'язані?
```

**Застосування у розслідуваннях:**
- Виявлення прихованих офшорних ланцюжків
- Атрибуція анонімних акторів до відомих мереж
- Прогнозування наступного кроку злочинної мережі

### Слайд 9 — Federated OSINT і приватність

**Проблема:** AI-OSINT масштабується настільки що стає інструментом масового стеження

**2025-2026 тренди:**
- EU AI Act обмежує масову біометрію
- Federated learning — AI навчається без централізації даних
- Privacy-preserving analytics — аналіз без доступу до сирих даних

**Питання яке галузь ще вирішує:**
Де межа між безпекою і масовим стеженням?

### Слайд 10 — Роль аналітика у 2028-2030

**Що зникне:**
- Ручний пошук і агрегація
- Базова дедуплікація
- Форматування звітів

**Що залишиться людині:**
- Визначення мети і завдання
- Оцінка етичних і юридичних меж
- Критична перевірка AI-висновків
- Інтерпретація в людському контексті
- Прийняття рішень і відповідальність

**"AI знімає рутину. Людина залишається суддею."** — незмінно

### Слайд 11 — Навички OSINT-аналітика майбутнього

**Технічні:**
- Розуміння AI-агентних систем
- Базовий Python для автоматизації
- Геопросторовий аналіз
- Критична оцінка AI-виводу

**Аналітичні:**
- Структуровані аналітичні методики (ACH, SAT)
- Статистичне мислення
- Розуміння мережевих патернів

**Правові та етичні:**
- GDPR, AI Act орієнтація
- Etика збору даних
- OpSec для власного захисту
