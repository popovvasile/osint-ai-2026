### Слайд 2 — Навіщо автоматизація?

**Без автоматизації:** аналітик вручну переглядає 50 джерел → 3-4 години
**З автоматизацією:** скрипт перевіряє 50 джерел → 5 хвилин

**Але автоматизація без гігієни = збір сміття:**
- Дублікати, хибні спрацювання, застарілі дані
- Юридичні ризики якщо ігнорувати rate limits і умови сервісів
- Баги = неправильні рішення

**Ціль:** якісний, відтворюваний, аудитований збір даних

### Слайд 6 — Базовий пайплайн збору

```python
# Простий OSINT-пайплайн
class OSINTPipeline:
    def collect(self, query):
        """Фаза 1: Збір з джерел"""
        results = []
        results += self.search_web(query)    # Brave/Google
        results += self.search_social(query) # соцмережі
        return results
    
    def deduplicate(self, results):
        """Фаза 2: Дедуплікація"""
        seen = set()
        return [r for r in results if r['url'] not in seen
                and not seen.add(r['url'])]
    
    def enrich(self, results):
        """Фаза 3: Збагачення"""
        for r in results:
            r['summary'] = self.ai_summarize(r['content'])
        return results
    
    def store(self, results):
        """Фаза 4: Зберігання"""
        pd.DataFrame(results).to_csv('osint_results.csv')
```

### Слайд 7 — Rate Limiting: критично важливо

**Чому:** API і сайти блокують агресивні запити

```python
from ratelimit import limits, sleep_and_retry
import time

@sleep_and_retry
@limits(calls=10, period=60)  # 10 запитів за хвилину
def api_call(url):
    return requests.get(url)

# Або простіше:
def safe_request(url):
    time.sleep(1)  # 1 секунда між запитами
    return requests.get(url)
```

**Правила:**
- Brave Search: 1с між запитами
- Jina AI: 2с між запитами
- При 429 (Too Many Requests): чекай 5с, потім 15с, потім зупинись

### Слайд 8 — Гігієна даних

**5 принципів чистих даних:**

1. **Нормалізація** — однаковий формат (UTF-8, ISO 8601 для дат)
2. **Дедуплікація** — одне джерело, одна версія
3. **Атрибуція** — кожна запис зберігає URL і дату збору
4. **Версіювання** — зберігати оригінальний HTML, не тільки витяжку
5. **Аудит** — лог що, коли і звідки зібрано

```python
# Мінімальна структура запису
record = {
    "content": "...",
    "source_url": "https://...",
    "collected_at": "2026-04-14T10:30:00Z",
    "collector": "brave_search",
    "query": "Іван Петренко TechUA"
}
```

### Стартовий шаблон пайплайну (Python)

```python
"""
OSINT Data Collection Pipeline
Базовий шаблон для студентів курсу AI for OSINT 2026
"""
import requests
import json
import csv
import time
from datetime import datetime, timezone

class SimpleOSINTPipeline:
    def __init__(self, output_file="osint_results.csv"):
        self.output_file = output_file
        self.results = []
        
    def search_jina(self, query, api_key):
        """Пошук через Jina AI"""
        url = f"https://s.jina.ai/{query}"
        headers = {
            "Authorization": f"Bearer {api_key}",
            "Accept": "application/json"
        }
        time.sleep(2)  # Rate limiting: 2с між запитами Jina
        response = requests.get(url, headers=headers)
        if response.status_code == 200:
            return response.json().get('data', [])
        return []
    
    def add_result(self, content, source_url, query, collector):
        """Додати результат з атрибуцією"""
        self.results.append({
            "content": content,
            "source_url": source_url,
            "query": query,
            "collector": collector,
            "collected_at": datetime.now(timezone.utc).isoformat()
        })
    
    def deduplicate(self):
        """Видалити дублікати за URL"""
        seen_urls = set()
        unique = []
        for r in self.results:
            if r['source_url'] not in seen_urls:
                seen_urls.add(r['source_url'])
                unique.append(r)
        self.results = unique
        return len(self.results)
    
    def save(self):
        """Зберегти у CSV"""
        if not self.results:
            print("Немає результатів для збереження")
            return
        keys = self.results[0].keys()
        with open(self.output_file, 'w', newline='', encoding='utf-8') as f:
            writer = csv.DictWriter(f, fieldnames=keys)
            writer.writeheader()
            writer.writerows(self.results)
        print(f"Збережено {len(self.results)} записів у {self.output_file}")
```

### Слайд — Batch інгест: автоматизація завантаження

**Завантажити папку з файлами:**

### Слайд — Python pipeline з SHATTERED API

```python
import httpx
import glob
from pathlib import Path

BASE = "http://localhost:8100/api"

def ingest_folder_to_shattered(folder_path: str, project_name: str):
    """Завантажує папку документів у SHATTERED"""
    
    # 1. Створи проєкт
    proj = httpx.post(f"{BASE}/projects", 
                      json={"name": project_name}).json()
    project_id = proj["id"]
    print(f"Project: {project_id}")
    
    # 2. Batch інгест
    result = httpx.post(f"{BASE}/ingest/ingest-path",
        json={
            "path": str(Path(folder_path).resolve()),
            "project_id": project_id,
            "recursive": True,
            "ocr_mode": "auto"
        }, timeout=30.0).json()
    
    batch_id = result.get("batch_id")
    print(f"Batch: {batch_id}, Jobs queued: {result.get('job_count')}")
    
    # 3. Моніторинг прогресу
    import time
    while True:
        status = httpx.get(f"{BASE}/ingest/batch/{batch_id}").json()
        done = status["completed_count"]
        total = status["total_count"]
        print(f"Progress: {done}/{total}", end="\r")
        if done >= total:
            break
        time.sleep(3)
    
    print(f"\nIngest complete! {total} documents processed.")
    return project_id

# Запуск
pid = ingest_folder_to_shattered("/data/investigation/", "Розслідування 2025-03")
```
