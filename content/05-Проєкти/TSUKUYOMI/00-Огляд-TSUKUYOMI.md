> **Репозиторій:** https://github.com/savannah-i-g/TSUKUYOMI

> **Сумісність:** Claude | GPT | Gemini

---

## Що це таке?

**TSUKUYOMI** — це промпт-інжиніринговий фреймворк для структурованого розвідувального аналізу. Проєкт не є окремою програмою — це набір спеціально розроблених `.tsukuyomi`-файлів (JSON-структури), які завантажуються у великі мовні моделі (Claude, GPT, Gemini) і перетворюють їх на систему, що відтворює workflow розвідувального аналітика.

Простіше: **замість того, щоб щоразу писати довгі промпти з нуля, ви завантажуєте готові модулі, і AI одразу «знає», як аналізувати за стандартами IC (Intelligence Community).**

---

## Навіщо OSINT-аналітику це знати?

| Проблема без фреймворку | Що вирішує TSUKUYOMI |
|------------------------|---------------------|
| AI дає розмиті, непослідовні відповіді | Структурований вивід у форматі IC |
| Треба заново «налаштовувати» модель кожен раз | Персистентний стан через session export/import |
| Немає стандарту впевненості у висновках | Confidence calibration за ICD 203 |
| Важко аналізувати кілька доменів (OSINT + GEOINT + економіка) | 26 спеціалізованих модулів |
| Складно передати задачу іншому аналітику | Єдиний JSON-формат, читабельний людиною і машиною |

## Швидкий старт (30 секунд)

```bash
git clone https://github.com/savannah-i-g/TSUKUYOMI.git
cd TSUKUYOMI
claude
```

Після відкриття Claude Code напишіть у чаті:

```
Initialise Amaterasu
```

Система ініціалізується і покаже меню доступних модулів.
