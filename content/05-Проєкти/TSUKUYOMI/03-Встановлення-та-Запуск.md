## Метод 1: Claude Code (рекомендований)

Це найпотужніший спосіб — Claude Code отримує повний доступ до файлів репозиторію, може редагувати модулі і зберігати сесії.

### Крок 1: Клонування репозиторію

```bash
git clone https://github.com/savannah-i-g/TSUKUYOMI.git
cd TSUKUYOMI
```

### Крок 2: Запуск Claude Code

```bash
claude
```

### Крок 3: Ініціалізація фреймворку

Після відкриття діалогу напишіть:

```
Initialise Amaterasu
```

**Що відбудеться:**
1. Claude завантажить і розбере `tsukuyomi_core.tsukuyomi`
2. Завантажить personality core AMATERASU
3. Просканує папку `modules/` і знайде всі 26 модулів
4. Покаже вітальне повідомлення і меню

**Очікуваний вивід:**
```
//TSUKUYOMI: Intelligent modular system initialized. Awaiting input or module selection.
```

## Метод 2: Claude Projects (без термінала)

Якщо у вас немає доступу до терміналу або ви хочете хмарний варіант:

### Варіант A: GitHub Sync (найкращий)

1. Відкрийте [claude.ai](https://claude.ai) → **Projects**
2. Створіть новий проєкт
3. У налаштуваннях проєкту додайте GitHub-репозиторій `savannah-i-g/TSUKUYOMI`
4. Усі файли синхронізуються автоматично
5. У чаті введіть: `Initialise Amaterasu`

> **Перевага:** При оновленні репозиторію нові модулі з'являться автоматично.

### Варіант B: Ручне завантаження

1. Завантажте ZIP з GitHub: `Code → Download ZIP`
2. Розпакуйте і завантажте файли в Project Knowledge
3. Введіть `Initialise Amaterasu`

> **Недолік:** Потрібно вручну оновлювати при нових версіях.

## Перевірка роботи системи

Після ініціалізації запустіть тест:

```
Activate module: data_recognition_ingestion
Input: "Test data: Company XYZ reported Q3 revenue of $2.3B, up 15% YoY. CEO John Smith announced expansion into Eastern European markets."
```

**Очікуваний формат відповіді:**

```
//RESULT: [Structured findings with entity extraction]
- Entity: Company XYZ (Organization)
- Entity: John Smith (Person, CEO)
- Metric: Revenue $2.3B, Q3, +15% YoY
- Indicator: Market expansion → Eastern Europe
//QUERY: [Any clarification needs]
```

Якщо вивід структурований з тегами `//` — фреймворк працює коректно.

## Часті проблеми

| Проблема | Причина | Рішення |
|----------|---------|---------|
| AI ігнорує теги `//` | Файли не завантажені | Перевірте, чи всі .tsukuyomi файли доступні |
| Модуль не знайдено | Неправильний шлях | Перевірте, що папка `modules/` є в проєкті |
| Відповіді без структури | Безкоштовний тариф | Рекомендується платна підписка (Claude Pro або вище) |
| `key.activationkey` не спрацьовує | Старий синтаксис Claude | Оновіть репозиторій (`git pull`) |
