## Встановлення (5 кроків)

```
1. git clone https://github.com/resistec/obsidian-osint-templates.git
   (або Download ZIP → розпакуйте)

2. Відкрийте Obsidian → "Open folder as vault"
   → Оберіть папку з клонованим репозиторієм

3. Settings → Community Plugins → вимкніть Safe Mode → Browse
   → Знайдіть "Templater by SilentVoid" → Install → Enable

4. Settings → Templater → Options:
   - "Template folder location" → /Templates
   - Увімкніть "Trigger Templater on new file creation"

5. Протестуйте: Ctrl+N → нова нотатка → Alt+E → Insert template → Person
```

> **Увага:** Якщо "Trigger on new file creation" увімкнено, Obsidian запитає шаблон при кожному створенні нотатки. Це зручно, але вимкніть, якщо хочете іноді створювати нотатки без шаблону.

## Плагіни: Обов'язкові

### 1. Templater (`SilentVoid13/Templater`)
**Навіщо:** Основа всього — дозволяє вставляти шаблони в нові нотатки.  
**Налаштування:** Template folder → `/Templates`

### 2. Auto Template Trigger (`numeroflip/obsidian-auto-template-trigger`)
**Навіщо:** Автоматично пропонує шаблон при створенні нотатки в певній папці.  
**Приклад:** Нотатки в `Investigations/Case-1/People/` автоматично отримують шаблон `Person`.

### 3. Update Time on Edit (`beaussan/update-time-on-edit-obsidian`)
**Навіщо:** Автоматично оновлює `updated:` у frontmatter.  
**Чому критично:** В розслідуванні важливо знати, коли востаннє оновлювалась нотатка. Без цього плагіна поле `updated` треба заповнювати вручну.

### 4. Omnisearch (`scambier/obsidian-omnisearch`)
**Навіщо:** Повнотекстовий пошук по всьому vault з попереднім переглядом.  
**Порівняно з вбудованим пошуком:** Знаходить входження в будь-якій частині нотатки, включаючи frontmatter.

### 5. Hierarchical Outgoing Links (`jasonmotylinski/hierarchical-outgoing-links`)
**Навіщо:** Показує всі вихідні посилання з поточної нотатки, згруповані за тегами.  
**Приклад:** Відкрили нотатку `Organization` — зразу бачите всі пов'язані `#person`, `#domain`, `#account` без перегляду тексту.

### 6. Quite Outline (`guopenghui/obsidian-quiet-outline`)
**Навіщо:** Пошуковий зміст кожної нотатки.  
**Альтернатива:** Create Note List — те саме, але маркований список.

### 7. Pandoc (`OliverBalfour/obsidian-pandoc`)
**Навіщо:** Експорт нотаток у PDF, Word, HTML.  
**Практичне застосування:** Фінальний звіт з розслідування → PDF для клієнта або суду.

## Плагіни: Важливі для OSINT

### Incomplete Files (`HananoshikaYomaru/obsidian-incomplete-files`)
**Навіщо:** Автоматично позначає нотатки, де є порожні поля.  
**Як це виглядає:** Іконка на нотатці сигналізує — тут ще є що заповнити.  
**Чому це важливо:** В розслідуванні на 200+ нотаток легко загубити ті, де атрибуція не завершена.

### Obsidian Priority Plugin (`Tekknoman/obsidian-prio-plugin`)
**Навіщо:** Пріоритезація конкретних блоків і рядків.  
**Приклад:** Позначте `Confidence: 3` у нотатці — і плагін підсвітить її як high-priority для подальшої верифікації.

### Link Archive (`tomzorz/obsidian-link-archive`)
**Навіщо:** Автоматично відправляє всі URL поточної нотатки до Wayback Machine.  
**Увага автора репозиторію:**
> "Be considerate, mission INFOSEC or ethical considerations regarding amplification may be contrary to this practice."
Якщо ціль ще не знає, що її досліджують — архівування URL може її попередити через server logs.

### Cryptsidian (`triumphantomato/cryptsidian`)
**Навіщо:** Шифрування vault локально.  
**Коли потрібно:** При передачі файлів колегам або зберіганні в хмарі.

### Graph Analysis (`SkepticMystic/graph-analysis`)
**Навіщо:** Використовує алгоритми (centrality, similarity) для виявлення неочевидних зв'язків між нотатками.  
**Практично:** Після завершення розслідування — останній прохід алгоритмом може виявити зв'язки, які ви пропустили.

### Leaflet (`javalent/obsidian-leaflet`)
**Навіщо:** Інтерактивні карти з геолокаційними даними прямо в нотатках.  
**Застосування:** Всі `Location` теги на одній карті → візуальні просторові зв'язки між сутностями.

### Python Scripter (`nickrallison/obsidian-python-scripter`)
**Навіщо:** Запуск Python скриптів прямо з Obsidian.  
**Застосування:** Результати Sherlock / Maigret / Holehe → автоматично в нотатки Account.

### RSS Plugin (`joethei/obsidian-rss`)
**Навіщо:** Підписка на RSS-стрічки прямо у vault.  
**Застосування:** Моніторинг медіа + автоматичне створення нотаток Event при появі релевантних новин.

## Рекомендована структура vault

```
.
└── Investigations/
    ├── Case-1/
    └── Case-2/
        ├── General Recon/
        │   ├── Organizations/
        │   ├── People/
        │   ├── Digital Accounts/
        │   ├── Assets/
        │   └── Intellectual Property/
        ├── Locations/
        └── Technical Recon/
            ├── Domains/
            ├── Hosts/
            ├── Phones/
            └── Emails/
```

З Auto Template Trigger налаштованим на папки — кожна нова нотатка в `People/` автоматично отримує шаблон `Person`, в `Domains/` — шаблон `Domain` тощо.

## Налаштування Graph View для OSINT

**Filters:**
```
path:Investigations/Case-2    ← тільки поточне розслідування
```

Вимкніть: tags, attachments  
Увімкніть: orphans (вузли без зв'язків — там де роботи найбільше)

**Groups (кольори):**
```
tag:#domain   → зелений
tag:#IP       → червоний
tag:#person   → синій
tag:#company  → помаранчевий
tag:#account  → фіолетовий
```

**Forces:**
- Link distance: 70-100 (щоб вузли не накладались)
- Center force: 0.3 (не занадто стиснуто)
- Repel force: 10-15
