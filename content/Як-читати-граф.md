# Як читати граф курсу

Граф у правій колонці — це **карта зв’язків між сторінками курсу**, а не граф розслідування (Person / Domain / Org). Ребра = внутрішні `[[wikilink]]` у markdown.

## Локальний граф

Показує **сусідів поточної сторінки** (глибина 1): урок → ДЗ / матеріали / наступний урок.

- Клік по вузлу — перехід на сторінку
- Поточна сторінка позначена кільцем і завжди має підпис
- Колір вузла = роль у курсі (див. легенду під графом)

**Ритуал:** відкрийте урок → подивіться локальний граф → перейдіть на ДЗ або матеріал-сусіда.

## Глобальний граф

Іконка в куті локального графа або **Ctrl/Cmd+G**. Показує весь vault:

| Колір / розділ | Що це |
|----------------|--------|
| Уроки | `01-Уроки` |
| ДЗ | `02-Домашні-завдання` |
| Матеріали | довідники, промпти, шаблони, статті |
| Проєкти | Obsidian templates, TSUKUYOMI, Hermes… |
| Кейси | практичні кейси |
| Мета | головна, цей гід |

На глобальному графі також з’являються **вузли тегів** (`#…`) — тематичні хаби між сторінками.

Наведіть курсор на вузол: підсвічуються сусіди, решта тьмяніє (`focusOnHover`).

## Мова аналітика

- **Хаб** — сторінка з багатьма вихідними посиланнями (наприклад, головна або хаб SOCMINT)
- **Кластер** — щільно пов’язана група (урок + ДЗ + матеріали одного модуля)
- **Острів** — майже без зв’язків → варто додати wikilink або це окремий артефакт

## Патерн хаб → категорія → сторінка

Застосовано до кейсів, проєктів, матеріалів, уроків і ДЗ. Для агентів / нових сторінок див. правило Cursor `.cursor/rules/course-graph-nodes.mdc`.

### Кейси

- Хаб `06-Кейси` → лише категорії (CTI, Шахрайство)
- Категорія → свої кейси + хаб
- Кейс → лише своя категорія
- Зовнішні розділи чіпляються до хаба, не до окремих кейсів

### Проєкти

- Хаб `05-Проєкти` → лише проєкти-категорії (Obsidian templates, TSUKUYOMI, Hermes) + хаб кейсів
- Категорія проєкту → усі сторінки модуля + хаб проєктів
- Сторінка модуля → лише своя категорія (без prev/next і cross-project edges)
- Головна й інші розділи входять через хаб проєктів

### Матеріали

- Хаб `03-Матеріали` → категорії: Довідники, SOCMINT, Промпти, Шаблони, Статті
- Категорія → свої сторінки + хаб матеріалів
- Сторінка → лише своя категорія
- Уроки / головна чіпляються до хаба матеріалів, не до окремих довідників

### Уроки та ДЗ (перетин)

Два хаби з навмисним перетином:

- Хаб `01-Уроки` → усі уроки + хаб ДЗ
- Хаб `02-Домашні-завдання` → усі ДЗ + хаб уроків
- Урок ↔ парне ДЗ (01↔01, 02↔02, 03↔03, 05↔08) — єдині ребра між деревами
- Урок без ДЗ → лише хаб уроків
- Немає prev/next ланцюгів між уроками чи між ДЗ; порядок видно в хабі

Так дерево лишається читабельним.

## Поруч із графом

- **Explorer** (ліворуч) — дерево папок
- **Backlinks** (під графом) — хто посилається *на* поточну сторінку
- Граф + backlinks разом дають двосторонній півотинг по курсу

## Що це *не* є

Це не Gephi / Neo4j і не граф сутностей з уроків про entity resolution. Для розслідувань використовуйте Obsidian-графи й інструменти з відповідних уроків; тут — навігація навчальної бази.
