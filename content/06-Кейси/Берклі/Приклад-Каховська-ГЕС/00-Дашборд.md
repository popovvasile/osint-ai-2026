# Дашборд розслідування

> Навчальне. Не для публікації. Як читати цей приклад — у нотатці [[00-Почніть тут]].

Волт повторює структуру звіту за Протоколом Берклі з домашнього завдання до Заняття №20. Усі таблиці — запити Dataview до властивостей нотаток: нова нотатка з шаблону зʼявляється в таблиці сама.

| Етап протоколу | Де у волті | Розділ звіту |
|---|---|---|
| Планування, оцінка ризиків | [[00-План розслідування]] | 3, 4 |
| Онлайн-пошук, попередня оцінка, відбір | `01-Пошук` | 5 |
| Збереження | `02-Артефакти` + `attachments` | 6 |
| Верифікація | `02-Артефакти`, [[00-Хронологія]] | 7 |
| Аналіз конкуруючих гіпотез | `03-ACH` | 8 |
| Висновки | `04-Висновки` | 2, 9 |
| Журнал роботи з ШІ | `05-Журнал-ШІ` | 10 |

Нова нотатка: правий клік на папці → «Нова нотатка» → назва з ID (`П-01 …`, `A-01 …`, `H1 …`, `I-01 …`) → **Alt+T** → шаблон.

## 1 · Журнал онлайн-пошуку

```dataview
TABLE WITHOUT ID file.link AS "№", час AS "Дата і час", інструмент AS "Платформа", мова AS "Мова", запит AS "Запит", результат AS "Що знайдено"
FROM "01-Пошук"
SORT file.name ASC
```

## 2 · Ланцюг збереження

```dataview
TABLE WITHOUT ID file.link AS "ID", вид AS "Тип", choice(url, elink(url, "відкрити"), "—") AS "URL", доступ AS "Дата і час доступу", choice(архів, elink(архів, "архів"), "—") AS "Архівна копія", choice(sha256, substring(sha256, 0, 12) + "…", "—") AS "SHA-256 файлу", зібрав AS "Хто зібрав"
FROM "02-Артефакти"
SORT file.name ASC
```

### Прогалини ланцюга

```dataview
TABLE WITHOUT ID file.link AS "ID", choice(архів, "є", "немає") AS "Архівна копія", choice(файл, "є", "немає") AS "Локальна копія", choice(sha256, "є", "немає") AS "Хеш"
FROM "02-Артефакти"
WHERE !архів OR !файл OR !sha256
SORT file.name ASC
```

## 4 · ACH: конкуруючі гіпотези

```dataview
TABLE WITHOUT ID file.link AS "Гіпотеза", формулювання AS "Формулювання", хто_стверджує AS "Чия версія", статус AS "Статус"
FROM "03-ACH"
WHERE тип = "гіпотеза"
SORT file.name ASC
```

Матриця: рядки — індикатори, стовпці — гіпотези. ✓ сумісний · ✗ несумісний · — не стосується.

```dataviewjs
const ach = dv.pages('"03-ACH"');
const hyps = ach.where(p => p.тип == "гіпотеза").sort(p => p.file.name);
const inds = ach.where(p => p.тип == "індикатор").sort(p => p.file.name);
const keys = hyps.map(h => h.file.name.split(" ")[0].toLowerCase()).array();
if (!keys.length || !inds.length) {
  dv.paragraph("Матриця зʼявиться, коли в папці `03-ACH` будуть гіпотези (`H1 …`) та індикатори (`I-01 …`).");
} else {
  const rows = inds.map(i => {
    const marks = keys.map(k => i[k] || "");
    const filled = marks.filter(m => m && m !== "—");
    const diag = filled.length < 2 ? "…" : (new Set(filled).size > 1 ? "так" : "ні");
    return [i.file.link, i.формулювання || "", i.надійність || "", ...marks, diag];
  }).array();
  dv.table(["ID", "Індикатор", "Надійність", ...keys.map(k => k.toUpperCase()), "Розрізняє?"], rows);
  const line = set => keys.map(k => `${k.toUpperCase()}: ${set.where(i => i[k] == "✗").length}`).join(" · ");
  dv.paragraph(`**Кількість ✗, усі індикатори:** ${line(inds)}`);
  dv.paragraph(`**Без індикаторів низької надійності:** ${line(inds.where(i => i.надійність != "низька"))}`);
  dv.paragraph("Найімовірніша гіпотеза — та, проти якої найменше ✗, а не та, за яку найбільше ✓. Індикатор, сумісний з усіма гіпотезами, нічого не розрізняє. Якщо висновок змінюється після відкидання слабких індикаторів — він тримається на слабких доказах.");
}
```
