## Сценарій

Людина отримала пропозицію інвестувати у "криптовалютний фонд" від особи яка представилась фінансовим консультантом. Завдання: перевірити особу і компанію через AI-OSINT.

---

## Red Flags список (загальні ознаки скаму)

### Особа
- [ ] Профіль створений недавно (LinkedIn менше 1 року)
- [ ] Фото профілю — результат зворотного пошуку = стокове фото або чужий аккаунт
- [ ] Немає реальних зв'язків (0 спільних знайомих)
- [ ] Нікнейм не підтверджується на інших платформах
- [ ] Освіта не верифікована (немає підтверджених з'єднань з університетом)
- [ ] Попередній досвід в "high-return investments"

### Компанія
- [ ] Не зареєстрована в офіційних реєстрах (ЄДР, Companies House тощо)
- [ ] Домен зареєстровано нещодавно (WHOIS)
- [ ] Відсутній фізичний офіс або адреса = virtual office
- [ ] Сайт — шаблонний, без унікального контенту
- [ ] Відгуки тільки позитивні і від нових акаунтів

## Методологія перевірки

### Особа
```bash
# 1. Зворотний пошук фото профілю
# Google Images / Yandex Images

# 2. Нікнейм на всіх платформах
python3 sherlock <nickname>

# 3. Email в витоках (з дозволу або для CTI)
# HaveIBeenPwned API

# 4. LinkedIn перевірка
bash scripts/apify.sh linkedin "<linkedin_url>"
```

### Компанія
```bash
# 1. WHOIS домену
whois company-domain.com

# 2. Реєстрація в ЄДР (Україна)
# opendatabot.ua або reyestr.court.gov.ua

# 3. Пошук відгуків і скарг
bash scripts/perplexity.sh sonar "company_name scam OR fraud OR відгуки"

# 4. Crosscheck адреси
# Google Maps → чи існує офіс?
```
